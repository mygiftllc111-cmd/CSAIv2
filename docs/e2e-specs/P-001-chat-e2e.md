# P-001 チャット画面 E2Eテスト仕様書

生成日: 2026-02-14
対象ページ: P-001 チャット画面
対象ルート: `/`, `/chat`, `/chat/:conversationId`, `/history`

## 正常系テストケース

### 利用申請フロー

- **E2E-P001-001**: 利用申請フォーム表示
  - 条件: 未登録ユーザー（LocalStorageにトークンなし）
  - 手順: 1. `/` にアクセス
  - 期待値: プロフィール入力フォーム（名前・所属・入社時期）が表示される

- **E2E-P001-002**: 利用申請送信
  - 条件: フォームに有効な値を入力済み
  - 手順:
    1. 名前「テスト太郎」を入力
    2. 所属「研修チーム」を入力
    3. 入社時期「2026-02」を選択
    4. 「利用申請を送信」ボタンをクリック
  - 期待値: 承認待ち画面が表示される

- **E2E-P001-003**: 承認待ち画面表示
  - 条件: 利用申請送信後（status: pending）
  - 手順: 1. 申請送信後のページを確認
  - 期待値: 「申請を受け付けました」メッセージとユーザー名が表示される

- **E2E-P001-004**: 承認状況確認ボタン
  - 条件: 承認待ち画面が表示されている
  - 手順: 1. 「承認状況を確認する」ボタンをクリック
  - 期待値: ステータスが再確認され、画面が更新される

- **E2E-P001-005**: 承認後のリダイレクト
  - 条件: 管理者が承認済み（status: approved）
  - 手順: 1. `/` にアクセス
  - 期待値: `/chat` にリダイレクトされ、チャット画面が表示される

### チャットフロー

- **E2E-P001-010**: 空状態表示
  - 条件: 承認済みユーザー、新規会話
  - 手順: 1. `/chat` にアクセス
  - 期待値: ウェルカムメッセージとサジェストチップが表示される

- **E2E-P001-011**: サジェストチップクリック
  - 条件: チャット画面の空状態
  - 手順: 1. 「有給休暇の取り方」チップをクリック
  - 期待値: メッセージが送信され、AIの回答が表示される

- **E2E-P001-012**: テキスト質問送信
  - 条件: 承認済みユーザー
  - 手順:
    1. テキストフィールドに「経費精算の方法を教えてください」を入力
    2. 送信ボタンをクリック（またはEnterキー）
  - 期待値:
    - ユーザーメッセージが右側に表示される
    - タイピングインジケーター（ドットアニメーション）が表示される
    - AIの回答が左側に表示される
    - 参照ソースタグが表示される
    - タイムスタンプが表示される

- **E2E-P001-013**: Enterキーで送信
  - 条件: テキストフィールドに文字が入力されている
  - 手順: 1. Enterキーを押す
  - 期待値: メッセージが送信される

- **E2E-P001-014**: Shift+Enterで改行
  - 条件: テキストフィールドに文字が入力されている
  - 手順: 1. Shift+Enterキーを押す
  - 期待値: テキストフィールド内で改行され、送信されない

- **E2E-P001-015**: 連続メッセージ送信
  - 条件: 既存の会話が進行中
  - 手順:
    1. 質問を送信
    2. AIの回答を待つ
    3. 追加質問を送信
  - 期待値: 同じ会話ID内でメッセージが追加される

- **E2E-P001-016**: 音声入力ボタン
  - 条件: Web Speech API対応ブラウザ
  - 手順: 1. マイクボタンをクリック
  - 期待値: マイクアイコンが録音状態（赤、パルスアニメーション）に変わる

- **E2E-P001-017**: 音声入力停止
  - 条件: 音声録音中
  - 手順: 1. 停止ボタンをクリック
  - 期待値: 録音が停止し、認識テキストが入力フィールドに表示される

### サイドバー・ナビゲーション

- **E2E-P001-020**: サイドバー表示（デスクトップ）
  - 条件: デスクトップ画面幅（900px以上）
  - 手順: 1. チャット画面を表示
  - 期待値: サイドバーが常時表示される（幅260px）

- **E2E-P001-021**: サイドバー非表示（モバイル）
  - 条件: モバイル画面幅（900px未満）
  - 手順: 1. チャット画面を表示
  - 期待値: サイドバーが非表示、ハンバーガーメニューが表示される

- **E2E-P001-022**: 最近の会話リスト
  - 条件: 過去の対話がある
  - 手順: 1. サイドバーを確認
  - 期待値: 「最近の会話」セクションに直近5件の会話が表示される

- **E2E-P001-023**: 会話の切り替え
  - 条件: サイドバーに会話リストがある
  - 手順: 1. サイドバーの会話をクリック
  - 期待値: URLが `/chat/{conversationId}` に変わり、該当会話のメッセージが表示される

- **E2E-P001-024**: 新しい会話ボタン
  - 条件: 会話進行中
  - 手順: 1. サイドバーの「新しい会話」をクリック
  - 期待値: `/chat` に遷移し、空のチャット画面（サジェストチップ付き）が表示される

### 対話履歴ページ

- **E2E-P001-030**: 対話履歴一覧表示
  - 条件: 過去の対話がある
  - 手順: 1. `/history` にアクセス
  - 期待値: 対話カード一覧（タイトル、日時、メッセージ数）が表示される

- **E2E-P001-031**: 履歴からチャット画面へ遷移
  - 条件: 対話履歴一覧が表示されている
  - 手順: 1. 対話カードをクリック
  - 期待値: `/chat/{conversationId}` に遷移し、該当会話のメッセージが表示される

- **E2E-P001-032**: 履歴が空の場合
  - 条件: 対話履歴がない
  - 手順: 1. `/history` にアクセス
  - 期待値: 「まだ対話履歴がありません」メッセージが表示される

### ログアウト

- **E2E-P001-040**: ログアウト
  - 条件: 承認済みユーザーがログイン中
  - 手順: 1. ヘッダーの「ログアウト」ボタンをクリック
  - 期待値: `/` にリダイレクトされ、利用申請フォームが表示される

## 異常系テストケース

- **E2E-P001-101**: 空のフォーム送信
  - 条件: フォームが空の状態
  - 期待値: 送信ボタンがdisabled、送信されない

- **E2E-P001-102**: 名前が長すぎる入力
  - 条件: 名前フィールドに51文字以上
  - 期待値: maxLength=50で入力が制限される

- **E2E-P001-103**: 空のメッセージ送信
  - 条件: テキストフィールドが空またはスペースのみ
  - 期待値: 送信ボタンがdisabled、送信されない

- **E2E-P001-104**: API通信エラー時
  - 条件: メッセージ送信でAPIエラー
  - 期待値: エラーメッセージ「申し訳ありません、一時的にエラーが発生しました」が表示される

- **E2E-P001-105**: 未承認でのチャットアクセス
  - 条件: status: pending のユーザー
  - 手順: 1. `/chat` に直接アクセス
  - 期待値: `/` にリダイレクトされ、承認待ち画面が表示される

- **E2E-P001-106**: 拒否ユーザーの画面表示
  - 条件: status: rejected のユーザー
  - 手順: 1. `/` にアクセス
  - 期待値: 拒否メッセージ画面が表示される

- **E2E-P001-107**: 音声入力非対応ブラウザ
  - 条件: Web Speech APIが未対応
  - 手順: 1. マイクボタンをクリック
  - 期待値: 非対応メッセージが入力フィールドに表示される
